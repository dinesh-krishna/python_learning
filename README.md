# Python Learning Repository

This repository is a structured Python study path covering the fundamentals, intermediate concepts, advanced features, data structures, algorithms, and practical patterns used in real-world Python development.

Each directory contains focused Python scripts that demonstrate a single concept or a small group of related topics, making it suitable for self-paced learning and quick revision.

## Repository Overview

The project is organized into progressive sections:

1. Basics and syntax
2. Data structures and collections
3. Functions and modularization
4. Object-oriented programming
5. Intermediate Python tools and practices
6. Functional programming and decorators
7. Context managers
8. Type hints and dataclasses
9. Concurrency and async programming
10. Advanced OOP and metaprogramming
11. Regular expressions and testing
12. Algorithms and data-structure fundamentals
13. Serialization, persistence, and datetime handling
14. Filesystem, CLI, and design patterns
15. Modern Python and memory optimization

## Suggested Learning Path

A practical order would be:

1. Start with the basics and data structures.
2. Learn functions, OOP, and modules.
3. Move into exception handling and file operations.
4. Explore decorators, context managers, and functional tools.
5. Study advanced OOP, regex, and testing.
6. Practice algorithms and collections.
7. Work through persistence, datetime, and CLI topics.
8. Finish with design patterns and modern Python features.

## How to Use This Repository

Each script can be run directly with Python. For example:

```bash
python "01_Basics/01_variables_and_datatypes.py"
python "03_Functions_and_Modules/01_functions_basics.py"
python "10_Concurrency/03_asyncio_basics.py"
```

You can also open the individual Python files for code examples and run them in order while studying each concept.
